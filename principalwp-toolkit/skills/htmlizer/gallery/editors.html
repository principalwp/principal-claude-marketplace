Editors

Two editors that change a Northwind pipeline run: flip feature flags against engine.settings.json, or tune the live shopper-intake prompt. Both read from the storefront orchestrator repo and submit only what you changed.

Pipeline feature flags

These map 1:1 to storefront/engine.settings.json. The model picks what the orchestrator runs on; each toggle adds or removes an agent from agents.excluded. The starting point is the repo's current config: the ten optional personas off, the seven always-on checks on.

Orchestrator model

Seeded from engine.model: "sonnet". NORTHWIND_ORCHESTRATOR_MODEL can override this at launch.
